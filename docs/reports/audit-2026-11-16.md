# Rà soát toàn bộ Lustra — 2026-11-16

Phạm vi: toàn bộ lõi Python, 6 extension, sidecar và app Electron. 4 reviewer độc lập đọc từng file, từng hàm; các lỗi nặng được kiểm chứng lại bằng script offline hoặc server cục bộ, không gọi tới website thật.

Nhãn:
- **[TH]**: đã tái hiện bằng code;
- **[MP]**: mô phỏng với hàm thật;
- **[ĐC]**: đọc code;
- **(Ruxx)**: lỗi có từ bản gốc.

Đã loại 1 phát hiện sai: "`ext.list` thiếu `capabilities`" (trường này đã có từ đợt lọc giới tính).

Trả lời 2 câu hỏi:
- **Search engine**: giai đoạn 1 đã làm nhưng còn lỗi ở mục B3–B6 và B12; giai đoạn 2 chưa làm (mục D7).
- **Chia thread/pool khi tải**: **phần lớn chưa cải tiến**. Lustra mới cải tiến lớp request API (session theo thread, rate limit, Retry-After, Cloudflare, trần lỗi proxy). Pipeline, pool và đường tải file vẫn y nguyên Ruxx (mục C).

## Đợt A — Bảo mật & mất dữ liệu — **ĐÃ SỬA (2026-11-16)**

Cách sửa từng mục:
- **A1:** id phải khớp regex và đường dẫn phải nằm trong `<data>/extensions`.
- **A2:** chặn `will-navigate` / webview / quyền; renderer chặn kéo thả; mọi IPC kiểm sender là trang của app.
- **A3:** cài extension chỉ qua `ext:installCatalog` / `ext:installRemote` (https + sha256 + hộp xác nhận native) / `ext:installZip` (file phải được chọn qua dialog, có xác nhận); `shell:open` chỉ mở thư mục; đổi `pythonPath` cần xác nhận native; catalog từ xa chỉ dùng URL https đã lưu trong settings.
- **A4:** key, cookies, headers, proxy truyền cho CLI qua biến môi trường `LUSTRA_SECRET_ARGS` (không còn trong argv); job gửi sang UI không còn chứa tham số; validator không in lại giá trị nhạy cảm; log sidecar và job được che key; `settings.json` quyền 0600; backend `basic_text` được báo là không mã hoá.
- **A5:** preview bỏ hẳn post không kiểm tra được tag khi bộ lọc bật (`hiddenNoTags`).
- **A6:** thumbnail chỉ tải từ host công khai (chặn IP nội bộ sau DNS), không cho chuyển hướng, giới hạn 25 MB / 20 s, kiểm content-type, ghi cache atomic, gộp request trùng.
- **A7:** tải vào `.part` rồi đổi tên; file đã có thì giữ nguyên; TOUCH không cắt cụt; bộ lọc file đã có bỏ qua `.part` và file rỗng, quét cả thư mục con, O(n+m).
- **A8:** so tới byte cuối.
- **A9:** cài theo giao dịch (stage, import thử, swap, rollback); bỏ qua thư mục ẩn và thư mục khác tên id; chặn symlink; giới hạn 50 MB / 2000 file sau giải nén; manifest kiểm kiểu chặt.
- Ngoài danh sách: sidecar chịu được dòng JSON không phải object hoặc byte hỏng.

Kiểm chứng:
- `lustra/tests/test_security.py` (18 test); toàn bộ 82 test offline pass.
- E2E Electron (`LUSTRA_SELFTEST_SECURITY=1`):
  - điều hướng bị chặn, cầu nối vẫn còn;
  - thumbnail `127.0.0.1` / `169.254.169.254` bị chặn;
  - cài zip không qua dialog bị từ chối;
  - `openPath` một file bị từ chối;
  - job không còn `args`;
  - preview và tải thật vẫn chạy.
